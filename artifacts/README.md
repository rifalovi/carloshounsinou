# 📐 Artefacts — diagrammes & présentations d'architecture

Cette section rassemble les **artefacts visuels** (diagrammes d'architecture, présentations
interactives) générés pour mes différents projets, afin de les **garder, versionner et
retrouver** au même endroit.

Chaque artefact est produit par la compétence [`diagramme-architecture`](../.claude/skills/diagramme-architecture/SKILL.md)
et rangé dans `artifacts/<slug-du-projet>/`. Ce fichier sert de **registre** (traçabilité).

## Comment en générer un

Dans Claude Code / Cowork, appeler la compétence :

```
/diagramme-architecture
```

…puis décrire le projet. L'artefact est enregistré ici **et** publié comme lien
partageable, et une ligne est ajoutée au registre ci-dessous.
